# Evaluate accountable coding parents before adoption

`code` and `implement` will be evaluated as Sol-medium coding parents that retain intent, decomposition, review, integration, validation, escalation, and final accountability while delegating bounded implementation to one Luna worker and evidence gathering to either `lookup` or `scout`. The parent and worker share the parent's checkout but never write concurrently, workers cannot delegate, and Sol-high remains the explicit fallback for architecture and difficult failures. This design aims to preserve Sol-high acceptance quality while reducing Sol usage, total cost, and elapsed time, but implementation will wait for a staged workload evaluation of worker effort, orchestrator effort, review behavior, and the complete topology.
